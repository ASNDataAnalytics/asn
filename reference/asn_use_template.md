# Use ASN Quarto Typst Template

Copies the ASN Typst extension and a starter Quarto document into the
specified directory.

## Usage

``` r
asn_use_template(path = ".")
```

## Arguments

- path:

  Character. Path to the target directory. Defaults to the current
  working directory.

## Value

Invisibly returns `NULL`. Called for its side effects.
